📊 WHAT IT DOES
────────────────────────────────────────────────────────────────────────────

Input:  [3, 6, 9, 12]
Output: 15

The application predicts the next number in arithmetic progressions by:
  1. Detecting the pattern (common difference)
  2. Calculating the next number
  3. Storing results in memory ("echoes")
  4. Displaying beautiful console output with statistics
