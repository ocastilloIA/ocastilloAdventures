🚀 QUICK START:
─────────────────────────────────────────────────────────────────────────────

1. Install dependencies (if not already done):
   npm install

2. Start the web server:
   npm run web

3. Open your browser:
   http://localhost:3000

4. You'll see the magical Echo Chamber interface!


📋 RUNNING MODES:
─────────────────────────────────────────────────────────────────────────────

Console Mode (original):
   npm run start
   or
   node index.js

Web Mode (new):
   npm run web
   or
   node server.js

Examples:
   node EXAMPLES.js


🔌 API ENDPOINTS:
─────────────────────────────────────────────────────────────────────────────

✓ POST /api/test
  - Test a sequence
  - Body: { sequence: [3, 6, 9, 12] }

✓ GET /api/memories
  - Get all stored memories

✓ GET /api/stats
  - Get chamber statistics

✓ DELETE /api/memories
  - Clear all memories

✓ GET /api/validate
  - Validate sequence without storing
  - Query: ?sequence=1,2,3,4
